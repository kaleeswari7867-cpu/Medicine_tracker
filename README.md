💊 Human Medicine Tracker

A simple and responsive web application designed to help users manage, track, and monitor their daily medicines.

The application allows users to add medicines, set dosage and timing information, track whether a medicine has been taken, and view basic medication statistics.

«Note: This project is a medication tracking and reminder system. It does not provide medical diagnosis, prescriptions, or treatment recommendations.»

---

🚀 Features

- 💊 Add and manage medicines
- 📋 Store medicine name and dosage
- ⏰ Set medicine time
- 🍽️ Specify before/after food
- 📅 Set medicine start and end dates
- ✅ Mark medicines as taken
- ⏳ Track pending medicines
- 🗑️ Delete medicines
- 📊 View daily medication statistics
- 💾 Store data using browser LocalStorage
- 📱 Responsive design for mobile and desktop

🖥️ How It Works

Step 1 — Add Medicine

Enter:

- Medicine name
- Dosage
- Time
- Food instruction
- Start date
- End date

Step 2 — Track Medicine

The medicine appears on the dashboard with its current status.

💊 Paracetamol

Dosage: 500 mg
Time: 08:00 AM
Food: After Food

⏳ Medicine Pending

Step 3 — Mark as Taken

When the medicine is consumed, click:

✓ Mark Taken

The status changes to:

✅ Medicine Taken

Step 4 — Monitor Progress

The dashboard displays:

Today's Medicines
       ↓
     Taken
       ↓
    Pending
